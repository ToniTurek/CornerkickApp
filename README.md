# Cornerkick-Manager

Cornerkick-Manager ist ein plattformübergreifendes Fußballmanager-Spiel, entwickelt mit .NET MAUI für Web-Anwendungen und als lokale App für Windows, Android und macOS.

Übernimm die Kontrolle über deinen Verein, plane Taktiken, entwickle Spieler, baue dein Stadion aus und führe deinen Club vom Amateurbereich bis in internationale Wettbewerbe.

## Features

- Echtzeit-Simulation aller Spiele
- Nationale Meisterschaften und internationale Wettbewerbe
- Karriere vom Interimstrainer bis zum Vereinsbesitzer
- Stadion- und Infrastruktur-Ausbau
- Umfangreiche Statistiken für Spieler, Vereine und Wettbewerbe
- Integrierter Editor
- Vollständig kostenlos
- Keine In-Game-Käufe

## Voraussetzungen

Für die Entwicklung wird benötigt:

- Windows 11 oder Windows 10
- Visual Studio 2022 (Version 17.10 oder neuer empfohlen)
- .NET SDK
- .NET MAUI Workload

## So kannst du Cornerkick bauen

### Projekt herunterladen

Repository klonen:

```bash
git clone https://github.com/ToniTurek/CornerkickApp.git
```

### Visual Studio installieren

1. Visual Studio Community herunterladen:
   https://visualstudio.microsoft.com/downloads/

2. Während der Installation folgende Workloads auswählen:

   - .NET Multi-platform App UI development (MAUI)

3. Installation abschließen

### Projekt öffnen

1. Visual Studio starten
2. Die Datei

   ```text
   CornerkickApp.csproj
   ```

   öffnen

3. Warten, bis alle NuGet-Pakete wiederhergestellt wurden

Falls erforderlich:

```bash
dotnet restore
```
